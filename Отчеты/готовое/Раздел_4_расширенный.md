# Практическая работа №4

## Сопровождение и восстановление работоспособности

### Цели
4.1. Резервная копия. 4.2. Восстановление данных. 4.3. Восстановление работоспособности. 4.4–4.5. Ошибки и отчёты. 4.6. Исправление кода. 4.7. Обслуживание по документации.

### Резервное копирование
Логическая копия: SqlPackage Export → PcConfiguratorDB.bacpac. Физическая: BACKUP DATABASE … WITH INIT, CHECKSUM. Регламент: полный еженедельно, дифференциальный ежедневно, bacpac перед обновлением.

**Скриншот:** export bacpac. Рис. 4.1.1.

### Восстановление
Import bacpac / RESTORE; сверка COUNT(*) по таблицам; удаление тестовых дубликатов перед промышленной эксплуатацией.

**Скриншоты:** строки после restore; вход после восстановления. Рис. 4.2.1, 4.3.1.

### Журналы и реестр ошибок
crash.log (Program.cs), журнал SQLSync в 1С. Реестр: номер, дата, модуль, описание, уровень, статус.

**Скриншоты:** crash.log; реестр. Рис. 4.4.1, 4.5.1.

### Исправления кода
Хранение паролей → хеш; anti-forgery на POST; очистка дубликатов данных.

**Скриншот:** код до/после. Рис. 4.6.1.
**Скриншот:** чек-лист обслуживания. Рис. 4.7.1.

Бэкапы, восстановление и реестр ошибок — база для ТЗ на сопровождение (раздел 5).
