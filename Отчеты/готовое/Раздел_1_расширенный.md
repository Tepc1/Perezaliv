# Практическая работа №1

## Основные этапы и методологии в проектировании и внедрении информационных систем

Рабочее место — менеджер-администратор интернет-магазина по продаже и сборке ПК. Учёт ведётся в 1С:УНФ; в рамках практики создаются веб-сайт PCRETAIL (ASP.NET Core 8), БД PCConfiguratorDB (SQL Server) и расширение 1С для синхронизации.

### Цели
1.1. Сценарий внедрения ИС. 1.2. ТЗ на внедрение. 1.3. График разработки. 1.4. Сравнение методологий.

### Сценарий внедрения (7 этапов)
1. Обследование — список функций и ролей.
2. Проектирование БД PCConfiguratorDB.
3. Разработка и развёртывание сайта PCRETAIL.
4. Расширение 1С и доступ к SQL.
5. Учётные записи Admin / Manager / Client.
6. Наполнение каталога и тестовых конфигураций.
7. Приёмочное тестирование.

Сценарий — «дорожная карта»: без него легко переделывать роли, схему SQL и подписки 1С.

**Скриншот:** схема сайт ↔ SQL ↔ 1С ↔ УНФ. Рис. 2.1.1.

### Техническое задание
Функции: каталог, конфигуратор, заявки, статусы, админка, синхронизация с 1С. Нефункциональные: .NET 8, Trusted Connection, бэкапы, журналирование (crash.log, SQLSync).

**Скриншот:** страница конфигуратора. Рис. 2.2.1.

### График и методология
Диаграмма Ганта по фазам. Выбраны итерации (ранние работающие срезы), а не чистый waterfall и не полный Scrum.

**Скриншоты:** Ганта; схема итераций. Рис. 2.3.1, 2.4.1.

### Вывод
Зафиксированы сценарий, основы ТЗ, график и выбор методологии для разделов 2–6.
