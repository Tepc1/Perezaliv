### Политика безопасности
| Требование | Факт | Действие |
| Пароли-хеш | Не выполнено | PasswordHasher / Identity |
| CSRF | Частично | ValidateAntiForgeryToken |
| Trusted Connection | Выполнено | Сохранить |
| Журналы | Выполнено | Ежедневный контроль |
| Минимальные права SQL | Не проверено | db_datareader/writer |
