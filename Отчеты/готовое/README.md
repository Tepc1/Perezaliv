## Как довести до 60–70 страниц
1. Вставить все рисунки выше (каждый 0,5–1 стр.).  
2. При необходимости увеличить интервал до 1,5 и поля по ГОСТ.  
3. Добавить титульный лист, содержание, список литературы и приложения из папки `Приложения`.
