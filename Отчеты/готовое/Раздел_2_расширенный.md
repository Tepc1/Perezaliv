# Практическая работа №2

## Анализ бизнес-процессов и предложения по развитию ИС

Без понимания процессов менеджера интерфейс получается «красивым, но бесполезным».

### Цели
2.1. Анализ бизнес-процессов. 2.2–2.3. Предложения по расширению. 2.4. Перечень обучающей документации. 2.5. Руководство оператора.

### Процесс «сборка конфигурации»
Клиент/менеджер собирает ПК на сайте → проверка совместимости → сохранение заявки → статусы → при необходимости синхронизация с 1С. Цель — убрать двойной ввод.

### Предложения (backlog)
A. Проверка совместимости (сокет, БП, один тип компонента). B. Личный кабинет. C. Хеширование паролей / Identity. D. Инкрементальная синхронизация с 1С. E. Уведомления менеджеру.

**Скриншот:** макет проверки совместимости. Рис. 2.2.1.

### Документация
Руководство пользователя, оператора, администратора; инструкция по установке. Руководство оператора: вход, заявки, каталог, контроль SQL-синхронизации.

**Скриншоты:** оглавление руководства; форма «Настройки синхронизации SQL» в 1С. Рис. 2.4.1, 2.5.1.

### Вывод
Процессы и backlog согласованы с тестированием (раздел 3) и реинжинирингом (раздел 6).
